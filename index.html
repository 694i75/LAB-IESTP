Falta iniciar el servidor local

No abras este archivo directamente

El navegador muestra una ruta del disco (file://). En ese modo bloquea los módulos y las vistas que necesita el portal; por eso el botón de acceso no puede iniciar la sesión.

Para abrirlo en Chrome o Edge

  1. Abre esta carpeta del proyecto en Visual Studio Code e inicia tu servidor local, por ejemplo con Go Live.
  2. Abre la dirección HTTP que indique el servidor, como http://localhost:5500. No uses la ruta que termina en index.html desde el disco.

También puedes abrir PowerShell en la carpeta del proyecto, ejecutar py -m http.server 8000 y visitar http://localhost:8000.
